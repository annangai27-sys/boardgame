Board Game Leaderboard PWA

How to use on iPhone:
1. Upload this folder to a static hosting service such as GitHub Pages or Netlify.
2. Open the hosted URL in Safari.
3. Tap Share > Add to Home Screen.
4. Open it from your Home Screen like an app.

Notes:
- It works offline after the first successful load.
- Data is saved locally in the browser/app storage.
- Use Export JSON regularly as backup, especially before changing phones or browsers.
